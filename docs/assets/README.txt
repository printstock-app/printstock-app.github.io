PrintStock GitHub版 更新手順（2026-08-03）

このフォルダの docs の「中身」を、GitHubリポジトリ
printstock-app/printstock-app.github.io の docs フォルダへアップロードしてください。

今回の更新内容
・栞がなくても、印刷ページを「1,3,5-7」のように飛び飛びで指定可能
・全角数字、全角カンマ、全角ハイフンにも対応
・指定ページを印刷履歴と再印刷設定に保存

アップロード後
1. GitHub Pagesの反映を1〜3分待つ
2. https://printstock-app.github.io/ を開く
3. 古い画面の場合は Chromeで Command + Shift + R を押す

注意
PDFと教材データはブラウザ内に保存されるため、この更新で削除されません。
念のため、更新前にPrintStockのバックアップを取るとより安全です。
