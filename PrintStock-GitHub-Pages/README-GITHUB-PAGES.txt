PrintStock 公開用パッケージ

1. このZIPを解凍します。
2. GitHub の printstock-app/printstock-app.github.io を開きます。
3. 「Add file」→「Upload files」を選びます。
4. このフォルダ内の「docs」フォルダと「.github」フォルダを、どちらも画面へドラッグします。
5. 「Commit changes」を押します。

GitHub Pages が GitHub Actions に設定済みなら、1〜3分後に次のURLで開けます。
https://printstock-app.github.io/

初回だけ、GitHub の Actions タブに表示される「Deploy PrintStock」が完了（緑のチェック）になるまで待ってください。
